# $ISNAD

**AI 智能体的信任层**

面向 Agent 互联网的权益证明审计协议。审计者质押代币为代码安全性背书。发现恶意代码则销毁质押；代码安全则获得收益。

## 问题

AI 智能体从不可信来源安装技能（skills）。一个恶意技能就能窃取凭据、泄露数据或入侵系统。目前没有标准化的信任评估方式。

## 解决方案

**权益证明审计：**
- 审计者质押 $ISNAD 为技能背书
- 发现恶意软件则销毁质押
- 安全的技能为审计者带来收益
- 用户安装前检查信任评分

## 词源

*Isnad*（إسناد）—— 阿拉伯语"传承链"。伊斯兰学术传统中通过追溯传述链来认证圣训的方法。一段圣训的可信度取决于其传述者链的可靠性。

$ISNAD 将这一古老智慧应用于代码溯源。
