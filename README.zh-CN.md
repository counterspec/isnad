# $ISNAD

**AI 智能体的信任层**

一个用于智能体互联网的权益证明审计协议。审计员质押代币为代码安全背书。恶意代码会烧毁质押。干净代码为审计员赚取收益。

## 问题

AI 智能体从不可信来源安装技能。一个恶意技能可以窃取凭证、外泄数据或危害系统。目前没有标准化的方式来评估信任度。

## 解决方案

**权益证明审计：**
- 审计员质押 $ISNAD 为技能背书
- 如果发现恶意软件，质押将被烧毁
- 干净技能为审计员赚取收益
- 用户在安装前检查信任分数

## 词源

*Isnad* (إسناد) — 阿拉伯语，意为"支持链"。伊斯兰学术传统中通过追溯传播链来验证圣训真实性。一句话的可信度取决于其叙述者。

$ISNAD 将这种古老智慧应用于代码溯源。
